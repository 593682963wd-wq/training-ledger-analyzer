# 离线培训台账分析

版本 0.1.0。本项目源码采用 MIT 许可证，见 LICENSE；第三方依赖仍适用各自上游许可。

从既有工作流提取清洗、KPI、部门聚合、月度趋势、讲师课时/费用排名、培训形式占比、评分分箱、按明确规则筛选候选，以及实际Pillow看板/海报绘图。没有AI模型、网络请求或公司系统接口，不附原工作簿、人员名单、图片、模板或字体。

## 运行

Python 3.13 实测；语法要求 Python 3.11+。安装依赖后可完全离线运行：

```sh
python3 -m pip install -r requirements.txt
python3 demo.py --demo --output outputs/synthetic
python3 -m unittest discover -s tests -v
```

`--demo` 新造三条2030年合成记录，输出练习工作簿和结果，不使用来源数据。已有输出目录会拒绝覆盖。全部操作无窗口；无需打开Excel、浏览器或桌面应用。

明确文件模式：

```sh
python3 demo.py --input sample.xlsx --config examples/config.json --output outputs/run-1
```

可选 `--sheet SHEET` 指定工作表；默认第一张。可选 `--font path/to/font.ttf` 提供有权使用、覆盖输入文字的字体。默认使用Pillow内置英文字体和英文图表标签；包含中文的输入必须显式提供相应字体。程序不扫描系统字体或下载字体。

## 输入与口径

XLSX表头使用 `report_dept, course, date, instructor, participants, hours, satisfaction, fee`；`form` 可选。这是通用字段契约，不带来源表头或机构专有样例。已有表头通过配置 `columns` 明确映射，例如 `{"Sample Course":"course"}`。重复表头、归一冲突、缺失标识和无效数字都会拒绝。

配置必须明确 `selection_rule.min_satisfaction`、`selection_rule.top_n`（1—5）和 `quality_edges`（2—5个严格递增的有限边界）。示例的0—100量表和65阈值仅为合成演示，不代表任何机构规定。评分必须位于该量表内；分箱是左开右闭，第一箱包含最小值。缺失评分不进入分箱和候选，也不伪造零分。

- 全部数字要求有限且非负，参训人次必须为整数。数字中的逗号、元、小时可清理；非数字文本直接报错。课时/费用/人次缺失默认报错，只有明确 `missing_numbers: "zero"` 才补零并记录说明。
- 日期接受完整日期、年月、Excel日期对象；月度输出保留年份。只给“2月”时必须明确 `default_year`，不从其它记录猜年份。无效日历日期和未标年份记录保留于总计，但从月度趋势/候选筛选中排除并写说明。
- `summary_labels` 只按显式标记排除课程或讲师列中的汇总行；默认不猜“合计”行。全空行排除。
- 总体评分按有效评分记录的正参训人次加权；没有正权重样本时为null。部门/排名里的评分保持原代码的记录算术平均，两者不混称。
- 候选先取最新有效月份（或明确 `latest_month`），逐条筛选评分达标记录，再按讲师聚合。按入选记录课时、均分、人次依次降序排名；不把未达标记录重新纳入此排名。展示课程是入选记录中最常见课程，不代表最佳课程或正式获奖认定。
- 培训形式按课时占比；全部课时为零时按记录数占比。图上最多五项，超过时末项合并为other，不丢分母。

## 输出与展示范围

`analysis.xlsx` 包含八张统计表；`summary.json` 包含KPI、候选和处理说明；`selected.csv` 是候选明细；`dashboard.png` 是概览；只有存在候选时才生成 `selected-poster.png`。表格导出把公式形状的文本保护为文本，不执行输入公式。

图为固定尺寸概览，部门只显示前七项、讲师排名前五项；完整聚合保存在Excel中。趋势线为分别归一高度的变化参考，不能以两条曲线高度直接比较课时与人次，真实数值看月度表。长名称/月份多的数据可能需要自行调整画布，当前仅验收合成短名称样例；程序不自动发布海报。

保留原 `AnalysisResult` 结构、聚合链和绘图主体；改为明确配置、严格数字/日期校验、空结果不造候选、字体上下文、尾项占比修正和表格文本保护。新增CLI装配和工作簿导出，未迁移来源的系统路径、业务表头别名、默认配置、原模拟名单、教程截图或启动脚本。

测试依赖版本：pandas 2.2.3、openpyxl 3.1.5、Pillow 12.3.0。第三方依赖及字体的使用/分发许可仍须按最终发布方式核对。来源文件路径、行号及哈希仅在私有审查材料中。
